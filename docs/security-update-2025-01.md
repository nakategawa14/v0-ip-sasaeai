# セキュリティアップデート - 2025年1月

## 概要

React Server Components（RSC）の脆弱性（CVE-2025-55184、CVE-2025-55183）に対応するため、Next.jsを最新の安全なバージョンにアップデートしました。

## 脆弱性の詳細

### CVE-2025-55184（高深刻度）
- **影響**: DoS（サービス拒否攻撃）
- **内容**: 悪意のあるHTTPリクエストによりサーバープロセスがハングし、CPUを大量消費する
- **影響範囲**: RSCリクエストを処理する全バージョン

### CVE-2025-55183（中深刻度）
- **影響**: ソースコード漏洩
- **内容**: 悪意のあるHTTPリクエストによりServer Actionsのコンパイル済みソースコードが返される可能性
- **リスク**: ビジネスロジックが露出する可能性（ハードコードされたシークレットは影響を受ける）

## 対応内容

- Next.jsを `16.0.7` から `^16.1.4` にアップデート
- セキュリティパッチが適用された最新バージョンを使用
