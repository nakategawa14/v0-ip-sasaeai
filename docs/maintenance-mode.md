# メンテナンスモードについて

## 現在の状態

サイトは現在メンテナンスモードになっており、全てのユーザーが `/maintenance` ページにリダイレクトされます。

## メンテナンスモードの解除方法

警察への届出が完了したら、以下の手順でメンテナンスモードを解除してください：

1. `proxy.ts` ファイルを開く
2. 以下の行を見つける：
   ```ts
   const MAINTENANCE_MODE = true
   ```
3. `true` を `false` に変更：
   ```ts
   const MAINTENANCE_MODE = false
   ```
4. ファイルを保存してデプロイ

## 必要な届出について

マッチングサービスは「インターネット異性紹介事業」として、以下の法律の対象となる可能性があります：

- **インターネット異性紹介事業を利用して児童を誘引する行為の規制等に関する法律**
- 管轄の警察署の生活安全課に届出が必要

### 届出に必要な書類（一般的な例）
- 事業届出書
- 事業計画書
- サービス利用規約
- プライバシーポリシー
- 年齢確認方法の説明書
- 運営体制の説明書
- 法人の場合：登記簿謄本

詳しくは管轄の警察署にお問い合わせください。
