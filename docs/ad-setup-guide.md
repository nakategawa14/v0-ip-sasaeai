# 広告設定ガイド

「ささえ愛」では、格安でのサービス提供のため、無料会員に広告を表示しています。

## 広告の種類

1. **Amazonアソシエイト**
   - バリアフリー関連商品や健康グッズなどの広告
   - アフィリエイト収益がサービス維持に貢献

2. **楽天ROOM**
   - 厳選した商品の広告
   - ユーザーに役立つ商品を紹介

## セットアップ手順

### 1. Amazonアソシエイト

1. [Amazonアソシエイト](https://affiliate.amazon.co.jp/)に登録
2. アフィリエイトタグ（例: `sasaeai-22`）を取得
3. `lib/ads/ad-config.ts` の `amazon.affiliateId` を更新

### 2. 楽天ROOM

1. [楽天ROOM](https://room.rakuten.co.jp/)に登録
2. ROOM IDを取得
3. `lib/ads/ad-config.ts` の `rakuten.roomId` を更新

### 3. 広告コンポーネント

`components/ads/ad-banner.tsx` のリンクを実際のアフィリエイトリンクに更新してください。

## 広告表示ルール

- **無料会員**: 全ページに広告表示
- **有料会員**: 広告非表示（快適な利用体験）

## 収益目標

- 有料会員: 1,000人 × 500円 = 月50万円
- 広告収益: サービス維持費の補填
- 合計で安定したサービス運営を実現
