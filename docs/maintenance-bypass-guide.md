# メンテナンスモード バイパスガイド

## 概要

サイトがメンテナンスモード中でも、管理者やテスターがアクセスできるようにする機能です。

## 使用方法

### 1. シークレットキーでアクセス

任意のページのURLに `?bypass=シークレットキー` を追加してアクセスします。

```
https://your-site.com?bypass=sasaeai-test-2024
https://your-site.com/login?bypass=sasaeai-test-2024
```

### 2. 自動的にクッキーが設定される

正しいシークレットキーでアクセスすると、ブラウザに7日間有効なクッキーが設定され、以降のアクセスではシークレットキーなしで全ページにアクセスできます。

### 3. バイパスの解除

ブラウザのクッキーをクリアすることで、バイパスが解除されます。

## シークレットキーの設定

### デフォルトキー

環境変数が未設定の場合、デフォルトのキーが使用されます:
- `sasaeai-test-2024`

### カスタムキーの設定

本番環境では、環境変数 `MAINTENANCE_BYPASS_KEY` でカスタムキーを設定してください:

```env
MAINTENANCE_BYPASS_KEY=your-secret-key-here
```

## メンテナンスモードの切り替え

### 有効化

`proxy.ts` ファイルで:
```typescript
const MAINTENANCE_MODE = true
```

### 無効化（サービス開始時）

```typescript
const MAINTENANCE_MODE = false
```

## セキュリティ注意事項

1. バイパスキーは関係者以外に共有しない
2. 本番環境では必ず環境変数でキーを設定する
3. 推測されにくい長いキーを使用する
4. 定期的にキーを変更する
5. テスト完了後はクッキーをクリアする

## トラブルシューティング

### バイパスが効かない場合

1. URLにシークレットキーが正しく追加されているか確認
2. ブラウザのクッキーが有効になっているか確認
3. プライベートブラウジングモードを使用していないか確認

### バイパスを強制解除したい場合

1. ブラウザの開発者ツールを開く
2. Application → Cookies → `maintenance_bypass` を削除
3. またはブラウザのクッキーを全て削除
